# Callnote — прототип расшифровки

Откройте `index.html` в современном браузере. Сервер и установка зависимостей не нужны.

Прототип демонстрирует интерфейс локального приложения для расшифровки созвонов. Встроенная демонстрация содержит пример текста и синтетическую дорожку без речи. Можно импортировать свой аудиофайл для прослушивания; пример текста при этом сохраняется и не является результатом распознавания файла.

## Запланированные возможности

- Локальное потоковое распознавание русского и английского.
- Совместимые открытые модели через адаптеры, выбор модели и языка.
- Сегменты с началом, концом и идентификатором говорящего; позднее — привязка отдельных слов.
- Переход от текста к аудио, подсветка активного фрагмента, перемотка и скорость воспроизведения.
- Копирование сплошного текста, временных меток относительно дорожки или абсолютного времени встречи, меток говорящего.
- Редактирование текста и имён говорящих, сохранение проекта и экспорт.

## Границы прототипа

Распознавание, диаризация, захват системного звука и загрузка моделей требуют отдельного движка и здесь не реализованы. Панель настроек показывает планируемую конфигурацию. Часы встречи задаются вручную; для импортированной записи приложение не угадывает время её создания. Волна иллюстративная и не вычисляется из импортированного аудио. Пользовательские файлы обрабатываются браузером без отправки на сервер.

4. Реализовать сохранение аудио, сегментов и настроек как проекта.
5. Добавить системный звук для выбранной ОС и упаковку приложения.
