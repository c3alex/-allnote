# Callnote 0.2.1 для macOS

Настольное приложение с локальной расшифровкой файлов и звонков. Сборка предназначена для macOS 14.4+ на Apple Silicon: `dist/Callnote.app`. Точный проверенный набор ОС и проверок указан в VALIDATION.md. Это ранняя версия, а не подписанный публичный релиз.

## Начало работы

1. Распакуйте архив и перенесите Callnote.app в «Программы».
2. Откройте «Модели», выберите Tiny/Base/Small или вставьте ссылку на совместимую модель Hugging Face.
3. Нажмите «Проверить модель», посмотрите размер и лицензию, затем «Скачать». После загрузки выберите установленную модель и нажмите «Использовать».
4. Выберите «Системный звук + микрофон», «Только системный звук» или «Только микрофон» и начните запись.
5. Разрешите macOS доступ к системной записи и/или микрофону. Если доступ ранее отклонён, кнопка «Доступ к звуку» открывает нужные настройки. Может потребоваться перезапуск приложения.

Приложение не записывает звук при запуске. Захват начинается только после нажатия кнопки или назначенной пользователем горячей клавиши.

## Источники аудио

На macOS системный звук поступает через Core Audio, микрофон — из AVAudioEngine. Исходные фрагменты сохраняются на диск отдельным процессом до распознавания. Системный звук и микрофон привязаны к общей монотонной шкале времени. При завершении собирается WAV: микрофон слева, системный звук справа; если выбран один источник, он дублируется в оба канала.

Это позволяет записывать собеседников в Zoom и других приложениях даже при работе в наушниках. Живой захват звонка требует отдельной проверки на вашем Mac после выдачи разрешений. Защищённый звук может не захватываться. Автоматическое восстановление после смены устройств пока не реализовано: следите за уровнями и перезапустите запись при исчезновении сигнала. При использовании динамиков микрофон может повторно записать голоса собеседников; эхоподавления в этой версии нет.

Текст появляется по мере обработки блоков примерно по 5 секунд. Медленная модель увеличивает задержку текста, но не блокирует запись на диск. На границах блоков возможны ошибки и обрывы слов. «Стоп» завершает захват и дорабатывает очередь; «Отменить обработку» сохраняет аудио и прекращает дальнейшее распознавание. Уже исполняющийся вызов модели заканчивается перед отменой.

Метки «Вы» и «Собеседники» обозначают источник звука. Автоматического разделения нескольких удалённых говорящих пока нет; имена можно исправлять вручную.

## Модели и перенос

Поддерживаются готовые модели faster-whisper/CTranslate2 с model.bin, config.json и tokenizer.json. PyTorch, GGUF и произвольные ONNX напрямую не импортируются. Каталог использует многоязычные модели Systran с Hugging Face. Модели с суффиксом .en предназначены только для английского.

Перед скачиванием проверяются метаданные и файлы, загрузка закрепляется за конкретной версией репозитория. Скачанная модель становится доступна только после завершения проверки файлов. Загрузка идёт по HTTPS в отдельном процессе без Hugging Face/Xet. Отображаются мегабайты и скорость; отмена завершает процесс сразу. Есть 12-секундный сетевой тайм-аут, до трёх попыток и ограничение 35 секунд без событий. Повтор использует HTTP Range для сохранённой части; при отсутствии поддержки Range файл перезаписывается целиком. Для больших файлов проверяется SHA-256 из каталога. Приложение не выполняет удалённый код репозитория.

«Импорт папки» копирует совместимую модель в библиотеку Callnote. «Экспорт папки» создаёт переносимую копию с метаданными и контрольными суммами. На втором компьютере используйте «Импорт папки»; интернет для распознавания не требуется. Загрузка моделей требует сети, распознавание выполняется локально на CPU (int8).

## Разделы и управление

Все настройки доступны через боковое меню внутри главного окна: «Текущая встреча», «Модели», «Горячие клавиши», «Доступ к звуку». Переключение разделов не прерывает загрузку. Настройки не открываются отдельными диалогами.

Раздел встречи: выбор источника, язык и модель, индикаторы уровня, редактируемая таблица, плеер, копирование и экспорт. Клик по времени переводит плеер к нужному месту.

Компактное окно: всегда поверх других окон, запуск/остановка, таймер, последняя фраза, копирование и переход в главное окно. Его можно перемещать стандартным заголовком окна. Закрытие компактного окна не останавливает запись.

На macOS по умолчанию: ⌘⌥R — запись/остановка, ⌘⌥C — копирование, ⌘⌥M — компактное окно. В настройках можно переназначить сочетания; дубликаты и занятые сочетания отклоняются. Используется регистрация Carbon hotkeys без чтения произвольных нажатий клавиш. На других ОС доступны только локальные сочетания в окне приложения.

## Данные

Модели, настройки и записи: `~/Library/Application Support/Callnote`. Кнопка «Папка записей» открывает записи. Для каждой встречи сохраняются исходные WAV-фрагменты, manifest, итоговый recording.wav и проект JSON. Автосохранение текста идёт примерно каждые 2,5 секунды; при следующем запуске предлагается восстановление последней расшифровки. Во время записи исходные фрагменты остаются на диске даже при сбое распознавания.

Экспорт JSON ссылается на аудио, а не включает его. Для переноса встречи скопируйте также аудиофайл. TXT поддерживает сплошной текст, метки относительно дорожки или абсолютное время встречи и имена говорящих.

## Разработка и сборка

Python 3.11, Swift compiler из Xcode Command Line Tools и macOS 14.4 или новее.

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r desktop/requirements.txt
python desktop/build.py
```

Сборка компилирует нативный AudioCapture, включает его в приложение, добавляет описания доступа macOS и локальную ad-hoc подпись. Developer ID и нотариализация Apple не настроены. Первая сборка может потребовать разрешения macOS при запуске; не меняйте системные защиты глобально.

Запуск из исходников после сборки нативного модуля: `python desktop/app.py`. Тесты: `PYTHONPATH=desktop python -m unittest discover -s desktop/tests -v`.

Предыдущая Windows x64 версия 0.1 находится в теге windows-0.1.0. Эта версия 0.2 реализует нативный захват для macOS; Windows-захват и обновлённая Windows-сборка в этом изменении не выпускались.

## Время запуска

До первого кадра не загружаются модель, NumPy, CTranslate2, ONNX Runtime и Qt Multimedia/FFmpeg. Инициализация плеера происходит при открытии аудио; модель загружается в рабочем потоке после начала обработки. Сетевых запросов при запуске нет.

Для сборки 0.2 измерено 5,35 с / 0,57 с / 0,48 с от запуска исполняемого файла до первого кадра окна и следующего прохода цикла событий. Каждый запуск использовал новый профиль. Измерения выполнены в offscreen-режиме на текущей машине, без очистки дискового кэша ОС; они не включают диалоги Gatekeeper, действия пользователя и первую загрузку модели. Это измеренный результат, не гарантия одинакового времени на любом Mac.

После сборки macOS автоматически выполняется проверка лимита 15 секунд. Для отдельного прогона:

```sh
python desktop/benchmark_startup.py dist/Callnote.app/Contents/MacOS/Callnote --runs 3 --limit 15 --offscreen --output desktop/startup-benchmark.json
```

## Исправления 0.2.1

Загрузчик вынесен из потока GUI в отдельный процесс. Кнопка «Отменить» прекращает даже зависший запрос, «Повторить» продолжает с сохранённого файла. Закрытие приложения отменяет текущую загрузку и автоматически закрывает окно после завершения процесса. Ошибки показываются прямо на странице моделей. Системные окна выбора папки и разрешения macOS остаются стандартными окнами ОС.

При проблемах: откройте «Модели», повторите проверку, затем загрузку. Если сервер не отвечает, приложение завершит попытку с ошибкой вместо бесконечного ожидания. Доступ к Hugging Face всё равно требует работающей сети.
