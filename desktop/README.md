# Callnote Desktop — ранняя версия

Исходный код настольного приложения для Windows и macOS. Python 3.11 рекомендуем для обеих платформ. Сборка macOS Apple Silicon доступна в `dist/Callnote.app` и `dist/Callnote-macOS-AppleSilicon.zip`. Windows и Intel Mac пока не собраны. Проверена на macOS 27.2; совместимость с более ранними версиями не проверена.

## Запуск на macOS

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r desktop/requirements.txt
python desktop/app.py
```

## Запуск на Windows (PowerShell)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r desktop/requirements.txt
.\.venv\Scripts\python.exe desktop/app.py
```

Первое распознавание скачивает выбранную модель из Hugging Face. Далее используется кэш. Для работы без сети выберите папку готовой модели faster-whisper/CTranslate2: нужны model.bin, config.json, tokenizer.json и связанные файлы модели. Произвольные GGUF/ONNX-файлы не поддерживаются этим адаптером. tiny/base/small — многоязычные модели; модели с суффиксом .en не распознают русский. Вычисления идут на CPU с int8.

Откройте аудио и нажмите «Расшифровать» либо «Записать микрофон». Для микрофона нужен доступ ОС и устройство, поддерживающее 16 кГц. Распознавание выполняется блоками по 5 секунд, а не пословно: на слабом CPU задержка может расти. Записи сохраняются в Documents/Callnote Recordings. «Стоп» завершает текущую обработку и дописывает накопленные блоки. Скачивание модели может завершаться не сразу после нажатия «Стоп».

Щёлкните время в таблице для перехода по аудио. Имена говорящих и текст редактируются в таблице. Автоматическая диаризация и захват системного звука пока не реализованы. Для расшифровки созвона можно импортировать готовую запись. Границы блоков микрофона могут снижать точность; непрерывный декодер с перекрытием запланирован отдельно.

Параметры копирования: сплошной текст, относительные метки, дата и время встречи, говорящие. Абсолютное время рассчитывается от введённого начала встречи. Для микрофона начало устанавливается при запуске аудиопотока после загрузки модели.

Проект JSON сохраняет текст и ссылку на исходное аудио, само аудио в проект не копируется. Правки не сохраняются автоматически. Перед открытием другого файла или закрытием приложения сохраните проект.

## Сборка

В активированном окружении:

```sh
python desktop/build.py
```

Запускайте отдельно на Windows и macOS. Результаты: `dist/Callnote/Callnote.exe` и `dist/Callnote.app`. Модели не включены в сборку. Сборки требуют проверки на целевой ОС; macOS-пакет получает локальную подпись, но не Developer ID и нотариализацию. Для публичного распространения потребуется подпись издателя.

Технические источники: https://github.com/SYSTRAN/faster-whisper и https://doc.qt.io/qtforpython-6/deployment/deployment-pyinstaller.html.

## Сборка Windows одним запуском

На Windows x64 установите Python 3.11 x64 с python.org, распакуйте исходники и запустите `Build-Windows.cmd`. Скрипт создаст отдельное окружение, установит зависимости, соберёт приложение, проверит запуск и создаст `dist/Callnote-Windows-x64.zip`. Первая сборка требует интернета. Получателю приложения Python не нужен. Распаковывать и передавать нужно всю папку Callnote, включая `_internal`; одного EXE недостаточно.

Для GitHub Actions загрузите проект в свой репозиторий, откройте Actions → Build Callnote for Windows → Run workflow. После успешного выполнения скачайте артефакт Callnote-Windows-x64. Workflow запускается только вручную, не публикует релиз и не подписывает EXE. Для запуска из чата требуется доступ к вашему репозиторию.

Windows-сборка ещё не выполнена: на текущем Mac нет Windows runner, а удалённый репозиторий не настроен. Скрипт проверки подтверждает только отсутствие сбоя при запуске; работа микрофона и качество распознавания проверяются отдельно.
