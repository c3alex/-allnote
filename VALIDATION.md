# Проверка прототипа

- Проверен синтаксис встроенного JavaScript через Node VM.
- Проверены уникальность HTML ID и наличие элементов, используемых прямыми селекторами.
- Проверена функция формирования копируемого текста: шесть фрагментов, относительное время, имена говорящих, сплошной текст без меток и абсолютное время встречи.
- Проверка интерфейса в браузере не выполнена: инструмент браузера заблокировал открытие локального `file://` URL. Визуальная компоновка, воспроизведение, импорт и системный буфер обмена требуют ручной проверки после открытия `index.html`.

Для ручной проверки: запустите демо, перейдите к 00:24, измените имя и текст, переключите параметры копирования, импортируйте короткий аудиофайл. При импорте текст остаётся демонстрационным.

## Desktop

Проверены AST-синтаксис app.py/build.py, формирование экспорта с комбинациями меток, переход абсолютного времени через полночь и длительности более часа.
Запуск GUI, распознавание и сборки не проверены: доступен Python 3.9, загрузка Python 3.11 через uv завершилась ошибкой DNS. Исполняемые пакеты Windows/macOS не созданы. Требуется проверка зависимостей, микрофона и мультимедиа на обеих ОС.

## Повторная проверка 2026-11-07

- Установлены Python 3.11.17 и зависимости; ошибка DNS разрешилась при разрешённой загрузке за пределами сетевой песочницы.
- Пройдена проверка настоящих Qt-компонентов в offscreen-режиме: создание Window, добавление сегмента, изменение текста, экспорт и выделение времени.
- Модель tiny загружена, VAD на тишине вернул пустой результат; отдельно завершился вызов декодера без VAD. Это проверка работоспособности движка, а не точности на речи.
- PyInstaller собрал macOS arm64 пакет. Готовый бинарник проработал 8 секунд без сбоя запуска в offscreen-режиме, после чего тест завершил его.
- `codesign --verify --deep --strict` завершился успешно (локальная ad-hoc подпись).
- Не проверены визуальный интерфейс, физический микрофон, точность RU/EN, Windows и Intel Mac. Qt сообщил предупреждения о свойствах аудиоустройства в тестовом окружении.
- macOS-пакет и ZIP находятся в dist, бинарные файлы исключены из Git. Набор установленных версий зафиксирован в desktop/requirements-macos-arm64.lock.

## Подготовка Windows x64

Добавлены Build-Windows.cmd, desktop/build_windows.py и ручной workflow GitHub Actions на windows-2022. Проверены синтаксис Python, структура YAML и отказ запуска Windows-сборки на macOS. Реальная Windows-сборка и её проверка пока не выполнены: Windows runner и Git remote недоступны. ZIP с исходниками не является готовым Windows-приложением.
