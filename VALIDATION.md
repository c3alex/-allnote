# Проверка прототипа

- Проверен синтаксис встроенного JavaScript через Node VM.
- Проверены уникальность HTML ID и наличие элементов, используемых прямыми селекторами.
- Проверена функция формирования копируемого текста: шесть фрагментов, относительное время, имена говорящих, сплошной текст без меток и абсолютное время встречи.
- Проверка интерфейса в браузере не выполнена: инструмент браузера заблокировал открытие локального `file://` URL. Визуальная компоновка, воспроизведение, импорт и системный буфер обмена требуют ручной проверки после открытия `index.html`.

Для ручной проверки: запустите демо, перейдите к 00:24, измените имя и текст, переключите параметры копирования, импортируйте короткий аудиофайл. При импорте текст остаётся демонстрационным.

## Повторная проверка 2026-11-07

- Установлены Python 3.11.17 и зависимости; ошибка DNS разрешилась при разрешённой загрузке за пределами сетевой песочницы.

Реализованы нативный ScreenCaptureKit + AVAudioEngine helper, независимая запись WAV-фрагментов, обработка файлов/очереди ASR, совмещение источников по общей временной шкале, главное/компактное окно Qt, настройка глобальных Carbon hotkeys, библиотека локальных моделей с Hugging Face/import/export и автосохранение.

Проверено:

- Реальные Qt-компоненты offscreen: таблица, правки, сортировка источников, предпросмотр, компактное окно и автосохранение; отложенный плеер создаётся при открытии аудио.
- Компиляция Swift с target macOS 14.4 arm64; синтетический native self-test: конвертация 48 kHz stereo в 16 kHz mono, отдельные источники и WAV-фрагменты.
- Сквозная синтетическая цепочка helper → JSON events → дисковая очередь → Whisper → стереозапись. Физические устройства при тесте не открывались.
- Hugging Face: реальная проверка Systran/faster-whisper-tiny, загрузка закреплённой версии, валидация, локальная обработка WAV без сети, переносимый экспорт.
- Регистрация и освобождение трёх глобальных сочетаний macOS вне песочницы. Срабатывание при активном Zoom отдельно не проверено.
- PyInstaller app 0.2, macOS Apple Silicon, локальная codesign-проверка, 10 секунд работы упакованного приложения без сбоя.
- После оптимизации: три запуска готового бинарника до первого кадра и следующего прохода event loop: 5353,42 / 573,21 / 478,82 мс. Бюджет 15000 мс пройден. В каждом запуске новый профиль; кэш ОС не очищался; offscreen. Детали: desktop/startup-benchmark.json. NumPy, ASR и QtMultimedia отсутствовали среди импортированных модулей к первому кадру.

Не проверено: живой Zoom/микрофон/системный аудиопоток — у тестового helper нет разрешений macOS (screen false, microphone denied). Проверка окна через CUA завершилась таймаутом; визуальная проверка новой нативной компоновки не выполнена. Нет нотариализации/Developer ID. Нет Intel/Windows сборки 0.2. Автоматическое восстановление после смены аудиоустройства и автоматическая диаризация нескольких удалённых участников не реализованы.

## Исправления загрузки моделей и встроенные настройки — 0.2.1

Выявленный риск 0.2: отмена зависела от callback прогресса Hugging Face/Xet; сетевые операции и нативная проверка модели выполнялись внутри процесса GUI, без отдельного ограничителя отсутствия прогресса. Точный сетевой сбой на компьютере пользователя не воспроизведён по его логам.

Исправление: отдельный QProcess запускает тот же упакованный бинарник в режиме model-job до импорта Qt. Загрузка — стандартный HTTPS с корневыми сертификатами certifi, сетевым тайм-аутом 12 с, тремя попытками, HTTP Range и проверкой размера/SHA-256. Watchdog завершает процесс после 35 с без событий. Отмена убивает процесс, оставляя .part для повтора. Установленная модель появляется только после проверки и атомарного переименования папки.

Проверено 12 автоматических тестов. Дополнительные проверки: переключение всех страниц внутри QStackedWidget без видимых QDialog; отмена намеренно зависшего процесса за 0,214 с с продолжающими работать Qt timers; срабатывание watchdog; продолжение оборванного файла; безопасный повтор при HTTP 200 вместо Range; отклонение неправильной контрольной суммы и Content-Range.

Проверка готового macOS .app, а не только исходников: inspect Systran/faster-whisper-tiny завершился за 1,01 с; скачивание 78 205 610 байт в новый пустой профиль — за 27,58 с, 52 события прогресса, проверка хэша и установка успешны. Детали: desktop/packaged-download-check.json. Запуск этой сборки до первого кадра в offscreen — 3,387 с, лимит 15 с выдержан (desktop/startup-benchmark-0.2.1.json).

Системные окна выбора файла и настроек разрешений macOS сохраняются; собственные настройки моделей, клавиш и доступа к звуку теперь страницы главного окна. Компактное окно записи остаётся отдельным. Живой захват Zoom этим исправлением повторно не проверялся.
